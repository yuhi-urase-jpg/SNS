# SNS企画書アプリ

TikTok / Instagram Reels / YouTube Shorts の縦動画企画書を作成・管理するブラウザベースのツール。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `SNS企画書アプリ.html` | メインアプリ。ダブルクリックでブラウザで起動。データは localStorage に保存 |
| `リール企画書_テンプレート.md` | Markdown ベースの企画書テンプレート（手書き派向け） |
| `リール企画書_記入例.md` | テンプレートの記入見本 |

## 主な機能

### 企画書まわり
- フォーム入力 → 保存 → Markdown 書き出し
- 11 カテゴリで企画書を分類（ダンス／企画／採用／ニュース／エンタメ／Howto／Vlog／商品紹介／ストーリー／インタビュー／その他）
- ステータス管理（ドラフト／確認中／承認済／投稿済）
- 投稿カレンダー（月次ビュー、チップはカテゴリ色）
- カテゴリ別の平均 KPI 集計（投稿済の実績データから算出）

### トレンド情報
- 「SNS TREND DAILY」ニュース記事風 UI
- TikTok / Instagram Reels / Z世代横断トレンドを記事カードで表示
- 「📝 ドラフト作成」ボタンで、トレンドから企画書の骨組みを 1 クリック生成
- 公式トレンドソース（TikTok Creative Center 等）へのリンク集
- 自分の発見ログ（日々のトレンド観察を記録）

### データ管理
- 全データを JSON で書き出し / 読み込み
- 架空のサンプル案件 15 件が初回起動時に自動投入

## 使い方

1. `SNS企画書アプリ.html` をダブルクリックして既定ブラウザで開く
2. 初回起動時に架空サンプル案件が自動投入される
3. サイドバーから「新規企画書」「企画書一覧」「投稿カレンダー」「トレンド」「設定」を切り替え

## 注意

- データはブラウザの localStorage に保存されるため、別ブラウザ・別 PC では見えない。バックアップは設定画面の「JSON 書き出し」で
- TikTok / Instagram には公開 API がないため、トレンドデータの自動更新は未対応（手動更新）
